 Abstract:

The Hospital Emergency-Room Triage System is a Java-based application developed to improve the organization and management of patients in a hospital emergency department. In an emergency room, patients may arrive with different medical conditions and levels of urgency. Managing patients manually or simply according to arrival time can make it difficult to identify critical cases quickly. This project provides a systematic method for registering patients, evaluating their severity, assigning priority levels, and managing the treatment queue. The system collects patient information such as patient ID, name, age, symptoms, and severity level. Based on the entered severity, patients are categorized into appropriate priority levels and organized in the emergency queue. The project demonstrates the practical application of Java programming concepts such as classes, objects, methods, conditional statements, loops, collections, encapsulation, exception handling, and data structures.
